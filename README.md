 # The Grind

A collection of my LeetCode solutions organized for consistent practice and long-term improvement. This repository tracks my daily problem solving across data structures and algorithms, focusing on patterns, clean code, and optimized approaches.

## Structure
- Solutions grouped by topic (Arrays, Strings, Hashing, Two Pointers, Dynamic Programming, Trees, Graphs, etc.).
- Each problem folder includes:
  - Problem name and link
  - Solution
  - Notes or explanation
  - Time and space complexity

## Purpose
To document my progress, strengthen problem-solving skills, and build a reliable reference for technical interviews.

## Languages
Primarily Python, with occasional solutions in other languages.

## Status
Continuously updated as new problems are completed.
